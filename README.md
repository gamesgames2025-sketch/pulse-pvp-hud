# PulsePvP HUD — Fabric 1.21.11

> **Важно:** 1.21.11 — последняя версия Minecraft, для которой Fabric ещё
> выпускает маппинги Yarn (те самые "человекочитаемые" имена классов/методов,
> использованные в этом коде). Начиная со следующей версии Fabric переходит
> на официальные маппинги Mojang, и код на Yarn придётся портировать.
> Для сборки нужен **Loom 1.14** и **Fabric Loader 0.18.1+**.

Клиентский информационный HUD-мод для PvP. **Не даёт механического преимущества**
(не бьёт за вас, не крутит камеру, не подсвечивает сквозь стены) — только выводит
данные, которые и так доступны игроку, в удобном виде. Это тот же принцип, что у
популярных HUD-модов (armor status, potion timers и т.п.), обычно разрешённых
на серверах — но правила у всех разные, уточните у админов конкретного сервера.

## Что делает

1. **Crit/Cooldown-бар** под прицелом — синяя полоса восстановления атаки,
   при готовности крита — жёлто-оранжевая пульсация с мигающей рамкой.
2. **Pulse HP/броня цели** — при наведении/ударе по существу сверху экрана
   появляется бар его здоровья (пульсирует быстрее и краснее при HP < 30%)
   и тонкая полоска брони под ним.
3. **Таймеры эффектов** цели — цветные плашки (зелёный = баф, красный = дебаф)
   с обратным отсчётом в секундах/минутах.

## Структура проекта

```
pvp-pulse-hud/
├── build.gradle
├── gradle.properties
├── settings.gradle
└── src/main/
    ├── java/com/example/pvphud/
    │   ├── PulsePvpClient.java      — точка входа, регистрация событий
    │   ├── CombatTracker.java       — сбор данных (цель, кулдаун, пульс-фаза)
    │   ├── PulseHudRenderer.java    — вся отрисовка 2D-оверлея
    │   └── mixin/AttackHookMixin.java — фиксация цели в момент удара
    └── resources/
        ├── fabric.mod.json
        └── pulsepvp.mixins.json
```

## Сборка

1. Установите JDK 21.
2. В корне проекта: `./gradlew build` (обёртку gradlew нужно сгенерировать
   через `gradle wrapper --gradle-version 8.8`, т.к. она не входит в архив).
3. Готовый jar — в `build/libs/`. Кладём в папку `mods` рядом с Fabric Loader
   и Fabric API соответствующей версии.

## Как расширять

- **Больше данных в пульс** — в `CombatTracker.tick()` добавьте свои поля
  (например, скорость игрока, расстояние до цели — метод `distanceToTarget`
  уже есть) и используйте их в `PulseHudRenderer`.
- **Другая "цель" пульса** — сейчас пульс завязан на `getPulseValue()`
  (синусоида, ускоряется вместе с кулдауном атаки). Можно привязать фазу
  к другим событиям: получение урона, активация щита и т.д.
- **Текстуры вместо цветных плашек** — замените `ctx.fill(...)` в
  `renderTargetEffects` на `ctx.drawTexture(...)` с текстурой иконки эффекта
  (`effect.getEffectType()` даёт доступ к id для поиска спрайта).
- **Настройки/конфиг** — добавьте Cloth Config API или простой JSON-файл,
  чтобы игрок мог включать/выключать модули и менять позиции баров.

## Важно про честность в PvP

Модуль сознательно не включает: авто-атаку, авто-крит-таймер с автокликом,
предсказание траектории снарядов противника, ESP/wallhack. Если сервер требует
"vanilla-like" клиент (например, античит с whitelist модов) — уточняйте
разрешённость HUD-модов у администрации до использования.
